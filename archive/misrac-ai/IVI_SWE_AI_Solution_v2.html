🎯 1 · Problem Statement
Giải quyết bài toán SWE.3/SWE.4 cho OEM/Tier-1 trong IVI
❓
Đặt vấn đề
Vận hành theo ASPICE đòi hỏi chất lượng và traceability cao. Trong V-model, cặp SWE.3 ↔ SWE.4 (Detailed Design/Unit Construction ↔ Unit Verification) là nơi tập trung nhiều effort thủ công lặp lại nhất — sửa lỗi QAC và viết Unit Test. Đây là điểm nghẽn cần đối mặt và giải quyết.
🔍 Pain-point tập trung ở đáy chữ V — chiếm ~80% effort lặp lại
ProcessVấn đề hiện tạiHệ quả
SWE.3 — Finding + Fix (QAC) Nhiều lỗi; phân loại & sửa thủ công, chậm, dễ bỏ sót Cycle time dài, backlog tồn đọng
SWE.4 — Unit Test (winAMS) Viết test tay, điền sheet thủ công dễ sai Coverage C0/C1 thấp, khó scale

→ Chất lượng phụ thuộc từng cá nhân. Cơ hội: tự động hóa đúng 2 khâu lặp lại này bằng AI mà vẫn giữ nguyên quy trình & nâng cao chất lượng.

🏆 Flezi Metis — nền tảng đã kiểm chứng của FPT (đội AI1)

⚙️ Tính năng chính
  • Code Knowledge Graph: index codebase C (tree-sitter → SQLite graph), hiểu quan hệ cross-file.
  • MCP tools: metis_explore (ngữ cảnh hàm), metis_callers (call graph), metis_impact (phạm vi ảnh hưởng).
  • LITE edition chạy on-prem, rất nhẹ (< 2GB RAM trên máy 8GB).
  • Tích hợp sẵn công cụ AI coding (Claude Code / Copilot / Cursor).
  • Cài đặt 3 bước: load image → init + index → add config.
🎁 Lợi ích chính
  • AI hiểu toàn cục codebase → fix & sinh test chính xác hơn, ít sai ngữ cảnh.
  • Tiết kiệm 30–60% token → giảm chi phí LLM đáng kể.
  • On-prem → source code không rời hạ tầng, bảo mật IP.
  • Đã kiểm chứng nội bộ FPT → giảm rủi ro triển khai (không xây từ đầu).
  • Linh hoạt ghép với Local LLM hoặc FPT AI Factory API.
  • Sẵn sàng mở rộng → có thể tích hợp vào luồng CI/CD tự động về sau (auto scan → fix → unit test → quality gate trong pipeline).
🛡️
Nguyên tắc an toàn: Grounding theo MISRA/CERT/CWE (mọi đề xuất kèm trích dẫn) · Human gate cho case rủi ro (pointer/struct, low-confidence) · Output schema-validated.
